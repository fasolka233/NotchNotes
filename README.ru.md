# NotchNotes

Лёгкая утилита для меню-бара macOS, живущая в области чёлки (notch) экрана. Нажмите **⌥ + Space**, чтобы выдвинуть компактную панель с заметками, задачами, таймером, историей буфера обмена и полкой для файлов — без окон, без иконки в Dock.

🇬🇧 [Read in English](README.md)

## Возможности

- **Notes** — быстрые заметки
- **Tasks** — простой список задач
- **Timer** — таймер обратного отсчёта / секундомер
- **Clipboard** — история буфера обмена
- **Shelf** — перетаскивайте файлы, чтобы держать их под рукой (drag & drop на панель или иконку в меню-баре)

Дополнительно:
- Глобальная горячая клавиша **⌥ + Space** для открытия/закрытия панели
- Иконка в меню-баре с быстрым доступом ко всем вкладкам
- Переключатель "Запускать при входе"
- Работает как фоновое accessory-приложение (без Dock-иконки, без обычных окон)

## Требования

- macOS 14.0+
- Swift 5.9+ (Xcode 15+ command line tools)

## Сборка и запуск

```sh
./build.sh debug --run     # собрать и запустить
./build.sh release         # только release-сборка
```

Скрипт собирает проект через `swift build`, упаковывает `build/NotchNotes.app` и подписывает его ad-hoc подписью.

## Self-check

Проверка внутренней логики без запуска UI:

```sh
swift run NotchNotes --selfcheck
```

## Данные

Данные хранятся локально в `~/Library/Application Support/NotchNotes`. Быстрый переход туда — через иконку в меню-баре → «Папка с данными».
